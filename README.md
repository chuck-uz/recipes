# Рецепты

Личная поваренная книга: рецепты рождаются в чате с Claude, живут в этом репозитории как JSON и приезжают в Android-приложение без пересборки.

- **[SPEC.md](SPEC.md)** — спецификация, источник правды.
- **[CLAUDE.md](CLAUDE.md)** — правила работы с контентом.
- `recipes/` — рецепты, по одному файлу на рецепт.
- `index.json` — собирается CI, руками не редактируется.

Приложение под Android собирается из `app/`; готовый APK — в [Releases](../../releases).

## Разработка

```bash
npm test              # тесты recipe-core: единицы, склонения, масштабирование
npm run content:check # валидация рецептов, как в CI
cd app && npm start   # Expo: телефон через Expo Go
cd app && npm run web # тот же интерфейс в браузере, для быстрой проверки вёрстки
```

Системный таймер работает только на настоящем Android: в браузере кнопка честно сообщит, что «Часы» недоступны.
